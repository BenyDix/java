### Алгоритм решения

3. Иначе — false.

## Задача 8. Возраст
### Текст задачи
Дана сигнатура метода: `public String age(int x);`
Необходимо реализовать метод таким образом, чтобы он возвращал строку с числом x и правильной формой слова: «год», «года» или «лет».
- «год» — если оканчивается на 1, кроме 11;
- «года» — если оканчивается на 2, 3, 4, кроме 12, 13, 14;
- «лет» — во всех остальных случаях.

### Алгоритм решения
1. Получаем последнюю цифру числа: `last = x % 10`.
2. Получаем две последние цифры: `lastTwo = x % 100`.
3. Если last == 1 и lastTwo != 11 — «год».
4. Если last в диапазоне [2; 4] и lastTwo не в [12; 14] — «года».
5. Во всех остальных случаях — «лет».

## Задача 10. Вывод дней недели
### Текст задачи
Дана сигнатура метода: `public void printDays(String x);`
Метод принимает название дня недели и выводит его и все последующие до конца недели. Если строка не является днём недели — выводится «это не день недели». Вместо if — использовать switch.
Пример: x="четверг" → четверг пятница суббота воскресенье

### Алгоритм решения
1. Открываем switch по строке x.
2. В каждом case, начиная с указанного дня, печатаем название и «проваливаемся» дальше (fall-through) до воскресенья.
3. В case «воскресенье» ставим break.
4. В default выводим «это не день недели».

## Задача 4. Добавление в массив
### Текст задачи
Дана сигнатура метода: `public int[] add(int[] arr, int x, int pos);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, содержащий все элементы arr, а в позицию pos вставлено значение x.
Пример: arr=[1,2,3,4,5], x=9, pos=3 → [1,2,3,9,4,5]

### Алгоритм решения
1. Создаём новый массив длиной на 1 больше исходного.
2. Копируем элементы arr с 0-го по pos-1 в те же позиции нового массива.
3. Записываем x в позицию pos.
4. Копируем оставшиеся элементы arr со сдвигом на 1 вправо.
5. Возвращаем новый массив.

## Задача 6. Реверс
### Текст задачи
Дана сигнатура метода: `public void reverse(int[] arr);`
Необходимо реализовать метод таким образом, чтобы он изменял массив arr — после работы массив должен быть записан задом наперёд.
Пример: arr=[1,2,3,4,5] → [5,4,3,2,1]

### Алгоритм решения
1. Проходим циклом только по первой половине массива (i от 0 до length/2).
2. Запоминаем элемент arr[i] во временную переменную.
3. Меняем местами arr[i] и arr[length - i - 1].
4. Записываем сохранённое значение в arr[length - i - 1].

## Задача 8. Объединение
### Текст задачи
Дана сигнатура метода: `public int[] concat(int[] arr1, int[] arr2);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором сначала идут элементы arr1, затем arr2.
Пример: arr1=[1,2,3], arr2=[7,8,9] → [1,2,3,7,8,9]

### Алгоритм решения
1. Создаём новый массив длиной arr1.length + arr2.length.
2. Копируем arr1 в позиции с 0 по arr1.length - 1.
3. Копируем arr2 со сдвигом на arr1.length: newArr[arr1.length + i] = arr2[i].
4. Возвращаем новый массив.

## Задача 10. Удалить негатив
### Текст задачи
Дана сигнатура метода: `public int[] deleteNegative(int[] arr);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив со всеми неотрицательными элементами arr.
Пример: arr=[1,2,-3,4,-2,2,-5] → [1,2,4,2]

### Алгоритм решения
1. Первым проходом считаем количество неотрицательных элементов.
2. Создаём новый массив нужной длины.
3. Вторым проходом копируем неотрицательные элементы, ведя отдельный счётчик для нового массива.
4. Возвращаем новый массив.
